Executive Dashboard API Reference

Technical integration guide for mobile applications retrieving ministry-wide asset valuations, inventory counts, approvals queue status, and category breakdowns.

GET /api/items/dashboard/executive

1 Dual Authentication & Authorization

This endpoint supports two flexible authentication methods. For a separate dashboard app, kiosk, or automated service, Method A (API Key) is strongly recommended as no user login or password management is required.

Method A: API Key (Recommended for Dashboard App)

Generate a key under Settings → API keys in the MoA-ATS web app. Pass it via the X-API-Key header:

X-API-Key Header 
X-API-Key: ats_live_<YOUR_API_KEY>

Method B: User Bearer Token (For User Sign-In)

For apps with user login screens, call POST /api/auth/login and pass the returned token:

Authorization Header 
Authorization: Bearer <YOUR_JWT_TOKEN>

2 Query Filters (Optional)

You can filter the aggregated statistics by store, category, item type, or calendar date range:

Parameter Type Description Allowed Values / Format
storeId String Narrows figures to items physically registered or held in a specific warehouse Location UUID or ID
category String Filters assets to one of the 8 MoA standard fixed asset categories
VEHICLE AGRI_MACHINERY IT_EQUIPMENT OFFICE_FURNITURE LAB_EQUIPMENT TOOLS_AND_EQUIPMENT OFFICE_SUPPLIES OTHER_SUPPLIES
itemType String Filters between capital fixed property and operational supplies FIXED, CONSUMABLE
from String Start of period (filter by voucher registration date) YYYY-MM-DD
to String End of period YYYY-MM-DD

4 Essential Business Rules for Mobile Devs

1. Active Inventory Only: totalItems and categoryBreakdown count Active On-Record Assets only (AVAILABLE in store + WITH_CUSTODIAN issued). Unapproved receipts in PENDING_STOCK_IN and DISPOSED items are strictly excluded so figures match the official government balance sheet.
2. Fixed vs. Consumables: The categoryBreakdown donut chart displays Fixed Capital Assets. Operational consumables (screws, paper, fuel) are quantified under consumableCount and consumableValuationETB.
3. Fleet Breakdown: In categoryBreakdown, motorcycles are separated into their own MOTORCYCLE row alongside VEHICLE for direct fleet visibility on mobile charts.

5 Mobile Integration Code Snippets

Dart (http package) 
import 'dart:convert';
import 'package:http/http.dart' as http;

Future<Map<String, dynamic>> fetchExecutiveDashboard(String token) async {
  final url = Uri.parse('https://<MOA_HOST>/api/items/dashboard/executive');
  
  final response = await http.get(
    url,
    headers: {
      'Authorization': 'Bearer $token',
      'Accept': 'application/json',
    },
  );

  if (response.statusCode == 200) {
    final body = jsonDecode(response.body);
    return body['data']; // Returns dashboard metrics
  } else {
    throw Exception('Failed to load dashboard: ${response.statusCode}');
  }
}
React Native (Fetch / Axios) 
export async function getExecutiveDashboard(token) {
  const response = await fetch('https://<MOA_HOST>/api/items/dashboard/executive', {
    method: 'GET',
    headers: {
      'Authorization': `Bearer ${token}`,
      'Accept': 'application/json',
    },
  });

  const json = await response.json();
  if (!response.ok) throw new Error(json.message || 'API request failed');
  return json.data;
}
Swift (URLSession) 
import Foundation

func fetchExecutiveDashboard(token: String) async throws -> [String: Any]? {
    guard let url = URL(string: "https://<MOA_HOST>/api/items/dashboard/executive") else { return nil }
    
    var request = URLRequest(url: url)
    request.httpMethod = "GET"
    request.setValue("Bearer \(token)", forHTTPHeaderField: "Authorization")
    request.setValue("application/json", forHTTPHeaderField: "Accept")
    
    let (data, response) = try await URLSession.shared.data(for: request)
    guard let httpResponse = response as? HTTPURLResponse, httpResponse.statusCode == 200 else {
        throw URLError(.badServerResponse)
    }
    
    let json = try JSONSerialization.jsonObject(with: data) as? [String: Any]
    return json?["data"] as? [String: Any]
}
